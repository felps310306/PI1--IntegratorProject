# Bibliografia - Projeto CashFy

Este documento compila as referências bibliográficas, técnicas e documentais utilizadas para a fundamentação teórica e o desenvolvimento prático do Painel de Inteligência Macroeconomica **CashFy**. As referências abrangem as fontes de dados, a stack tecnológica, a modelação analítica e a legislação vigente.

## 1. Fontes de Dados Oficiais Governamentais
* **BANCO CENTRAL DO BRASIL (BCB).** *Sistema Gerenciador de Séries Temporais (SGS).* Disponível em: <https://www3.bcb.gov.br/sgspub/>. Acesso em: 2026.
* **INSTITUTO BRASILEIRO DE GEOGRAFIA E ESTATÍSTICA (IBGE).** *Sistema IBGE de Recuperação Automática (SIDRA).* Disponível em: <https://sidra.ibge.gov.br/>. Acesso em: 2026.

## 2. Engenharia de Dados e Programação
* **MCKINNEY, Wes.** *Python for Data Analysis: Data Wrangling with Pandas, NumPy, and IPython.* 3. ed. Sebastopol: O'Reilly Media, 2022.
* **PYTHON SOFTWARE FOUNDATION.** *Python Language Reference*. Disponível em: <https://www.python.org>. Acesso em: 2026.
* **REITZ, Kenneth.** *Requests: HTTP for Humans.* Documentação Oficial. Disponível em: <https://docs.python-requests.org/>. Acesso em: 2026.

## 3. Modelação de Dados e Business Intelligence
* **KIMBALL, Ralph; ROSS, Margy.** *The Data Warehouse Toolkit: The Definitive Guide to Dimensional Modeling.* 3. ed. Indianapolis: Wiley, 2013. (Referência principal adotada para a estruturação do modelo *Star Schema*).
* **FERRARI, Alberto; RUSSO, Marco.** *The Definitive Guide to DAX: Business intelligence for Microsoft Power BI, SQL Server Analysis Services, and Excel.* 2. ed. Microsoft Press, 2019. (Referência fundamental para a criação de medidas de conversão e formatação de escalas financeiras em linguagem DAX).
* **MICROSOFT.** *Documentação Oficial do Power BI.* Disponível em: <https://learn.microsoft.com/pt-pt/power-bi/>. Acesso em: 2026.

## 4. Engenharia de Software e Metodologia Ágil
* **SCHWABER, Ken; SUTHERLAND, Jeff.** *O Guia do Scrum: O Guia Definitivo para o Scrum: As Regras do Jogo.* 2020. Disponível em: <https://scrumguides.org/>.
* **GITHUB.** *GitHub Pages Documentation.* Disponível em: <https://docs.github.com/pt/pages>. Acesso em: 2026. (Utilizado como referência para a hospedagem do código-fonte e o deploy da interface web).

## 5. Legislação, Segurança e Conformidade
* **BRASIL.** *Lei Geral de Proteção de Dados Pessoais (LGPD).* Lei nº 13.709, de 14 de agosto de 2018. Brasília, DF: Presidência da República, [2018]. Disponível em: <http://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/L13709.htm>. Acesso em: 2026.
